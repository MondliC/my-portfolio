# Mondli Nkosi Security Portfolio

A responsive single-page portfolio built with plain HTML, CSS and JavaScript.

## Features
- Security / cloud themed responsive design
- Interactive terminal intro
- Project category filtering
- Expandable case studies
- Scroll reveal animations
- Mobile navigation
- Sections for skills, certifications, projects and career journey

## Run locally
Open `index.html` directly in your browser, or use a local web server such as VS Code Live Server.

## Personalise before publishing
- Replace the LinkedIn placeholder link with your real LinkedIn profile URL.
- Add a downloadable CV link if desired.
- Add screenshots to the project cards for stronger visual impact.
- Deploy free with GitHub Pages, Netlify or Vercel.
